Generate text, images, video, or music with Gemini. Attach mixed Sources (image, video, text, PDF, audio) — or a folder collection for batch jobs (OCR every scan, apply a filter, reconstruct a magazine PDF, make a flipbook). Two or more tray sources still CREATE an illustrated report (prompt summarize for a document you can Export PDF — not a new video). One screenshot or clip: prompt extract the text, transcribe, or extract the layout. Pick models in Settings. Review output before you rely on it.

Toggle tools for this Studio session without opening Settings. Settings → Use Tools is the default on launch.

Tools

    Attach tools for this run, then reference them by alias in Tool Use (for example: use browse_web on a URL, or execute_powershell on c:\scripts\getdir.ps1 then write_text the stdout). File tools need absolute paths. Tools apply to text generations.

    Menu → Load Files / Folder (or Load Text / Image / Video / PDF) adds attachments to the Sources pane — Studio is the hub, so you do not have to pass through the image editor. With two or more tray sources, CREATE writes a cited illustrated report (pictures stay in the Viewer; Export PDF includes them). A large folder becomes one Collection — prompt it to OCR every scan, apply a filter, reconstruct a magazine PDF, or make a flipbook. One screenshot or clip still works as a visual basis: prompt extract the text, transcribe, or extract the layout. After a layout extract, ask Studio to recreate the UI as HTML/CSS or an app. Click a source to preview it; text scrolls in the pane. To OCR one picture among several, quote its title or filename (⋯ inserts the filename) or select that row, then prompt extract the text. Use ⋯ on a source to add its filename to the prompt, copy it, or remove it. For a song, Use as Basis adds the track as a source (for reports) and can reload lyrics as text for a new Lyria clip.

      Gemini API

      Generation uses this API key (stored in config.yaml). The OAuth client below is only for Gmail, Drive, Docs, Calendar, and Tasks tools — it does not replace the key. Get a key at aistudio.google.com/apikey.

      Google Workspace

      One OAuth token for Gmail, Drive, Docs, Calendar, and Tasks tools. Create a Google Cloud project, enable the Gmail, Google Drive, Google Docs, Google Calendar, and Google Tasks APIs, and download an OAuth client JSON (Desktop application type). Pick it below, then Connect Google Workspace once (re-connect after adding APIs so new scopes are granted). Access tokens last about an hour; Creator refreshes them automatically. If you have to reconnect every week, publish the OAuth consent screen (Testing → In production) in Google Cloud Console, then Connect Google Workspace again.

      Storage

      Image, video, song, and PDF files go here (PNG, MP4, MP3, PDF). Text, lyrics, prompts, and metadata stay in archives.json — you do not need to Export to keep them. Default is the media folder next to the app. When you change the folder you can move existing media files into the new folder; declining leaves them where they are. Archives still opens items left in the old project media folder.

      Video Editor requires a current ffmpeg on PATH (https://ffmpeg.org/ or winget install ffmpeg). Avoid outdated copies under Python\Scripts (see config.example.yaml).
